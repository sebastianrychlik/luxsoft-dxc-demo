# Prompt — M1.1 Frontend–Backend Local Integration

## Milestone

M1.1 — Frontend–Backend Local Integration

## Objective

Create the first working local integration between the Angular frontend and the Spring Boot backend.
The Angular application calls the existing backend health endpoint and displays the backend status in the UI.

## Scope

- Inspect the existing Spring Boot `GET /api/health` endpoint.
- Configure Angular `HttpClient` (already present via `provideHttpClient` + interceptors).
- Create a strictly typed `HealthResponse` frontend model.
- Create a `HealthService` that calls the backend through the existing `ApiService`.
- Update the dashboard component with reactive loading / success / error states.
- Create `proxy.conf.json` routing `/api` to `http://localhost:8080`.
- Wire the proxy into `angular.json` serve configuration.
- Update `environment.ts` to use a relative `/api` base URL (compatible with the proxy).
- Update documentation.

## Out of Scope

- No database access.
- No authentication.
- No exchange-rate functionality.
- No Git operations.

## Key Decisions

| Decision | Rationale |
|---|---|
| Angular dev proxy instead of CORS | Avoids permissive CORS; keeps local dev aligned with production same-origin deployment |
| Signals for reactive state | Native Angular 17+ API; no third-party state library needed |
| Discriminated union for UI states | Prevents invalid state combinations; type-safe template narrowing |
| `environment.apiBaseUrl = '/api'` in dev | Proxy handles forwarding; no `localhost` URL in service code |

## Result

All items in the Definition of Done were satisfied:

- Angular builds successfully.
- Spring Boot builds successfully.
- `HttpClient` is configured with logging and error interceptors.
- `HealthResponse` model is strictly typed.
- `HealthService` calls backend through `ApiService`.
- Dashboard displays loading, success, and error states.
- Retry action re-triggers the request.
- Proxy routes `/api` to `localhost:8080`.
- No `localhost` URL is hardcoded in Angular service code.
- Documentation complete.
